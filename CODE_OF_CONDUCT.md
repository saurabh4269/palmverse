# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion about the work. This includes respect for the cultural traditions the project draws on and for the people who practise them.

To report unacceptable behaviour, use GitHub's private reporting to the repository owner ([@saurabh4269](https://github.com/saurabh4269)) or open a minimal issue asking to be contacted. Reports are handled confidentially.
